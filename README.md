# Vaultlas Frontend

Frontend de Vaultlas — plataforma de gestión financiera personal. Interfaz moderna dark-mode construida con Next.js y Tailwind CSS con identidad visual Vaultlas.

## Stack

- **Next.js 14** — Framework React
- **Tailwind CSS** — Estilos utilitarios
- **SWR** — Data fetching
- **Chart.js** — Gráficos de reportes

## Paleta Vaultlas

- Verde Neón (#CCFF00) — Primario
- Verde Esmeralda (#10B981) — Ingresos
- Rojo Coral (#EF4444) — Egresos
- Negro Profundo (#0F0F0F) — Fondo
- Gris Oscuro (#1A1A1A) — Cards

## Inicio rápido

```bash
cp .env.example .env.local
npm install
npm run dev
```

Disponible en: http://localhost:3000

## Despliegue (Dokploy)

Conectar este repositorio en Dokploy. Usará el `Dockerfile` de la raíz.
